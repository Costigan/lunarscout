# Lunarscout Documentation

Lunarscout is the standalone Python library for lunar terrain, raster, temporal, and optional native lighting analysis.

This repository was split from Lunar Analyst so the calculation library can mature independently of the agent, web UI, FastAPI service, and application job framework.

Start with the [Lunarscout User Guide](USER_GUIDE.md).

For public signatures and source docstrings, see the generated
[API Reference](API_REFERENCE.md). It includes notices where explicit argument
documentation is missing from source docstrings.

The same generated content is available as
[API Documentation](API_DOCUMENTATION.md).
